# 모루결-오픈-프로젝트

모루결이 개발한 오픈소스 프로젝트 및 도구.

이 저장소는 **모루결이 만든 것들을 세상에 꺼내놓는 창구**입니다. 혼자 쓰고 끝내는 도구가 아니라, 누군가 가져다 쓰고 고치고 같이 키울 수 있도록 공개합니다.

## 무엇을 올리나

- 헤르메스(Hermes) 위에서 돌아가는 자동화 도구 — 감시, 정리, 백업, 보고
- 반복 작업을 없애는 스크립트와 파이프라인
- 실제로 쓰면서 검증한 운영 노하우(문서 형태)
- 실험했다가 남긴 재사용 가능한 부품

올리지 않는 것: 비밀키, 개인 계정 정보, 사내 전용 설정.

## 어떻게 쓰나

프로젝트별 폴더마다 `README.md`에 실행 방법을 적습니다. 공통 원칙은 세 가지입니다.

1. **의존성 최소** — 표준 런타임(Python/Node/PowerShell)과 공개 패키지만 사용
2. **비밀값 분리** — 모든 키는 환경변수나 `.env`로만 받고 코드에 넣지 않음
3. **실측 우선** — "된다"는 말 대신 명령 출력, 포트, 로그로 증명

## 참여 방법

- 버그/아이디어: [Issues](../../issues)에 남겨주세요. 템플릿이 있습니다.
- 코드 수정: Fork → 브랜치 → Pull Request. `CONTRIBUTING.md`를 먼저 읽어주세요.
- 질문/잡담: [Discussions](../../discussions)를 씁니다.

PR은 가능한 한 빠르게 확인하고, 답을 드립니다. 늦어지면 늦어진다고 말씀드립니다.
